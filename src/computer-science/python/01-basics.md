## Variables and arithmetic

```python,editable
price = 19.99
quantity = 3
total = price * quantity

print("Price:", price)
print("Quantity:", quantity)
print("Total:", total)
```

## Conditions

```python,editable
temperature = 24

if temperature >= 30:
    print("It is a hot day.")
elif temperature >= 20:
    print("It is a pleasant day.")
else:
    print("It is a cool day.")
```
