# Trees

Trees organize data hierarchically instead of linearly.

## In this section

- `Binary Tree`: general tree with at most two children
- `Binary Search Tree`: ordered binary tree
- `BST Insert and Remove`: core update operations
- `Depth-First Search`: preorder, inorder, postorder
- `Breadth-First Search`: level-order traversal
- `BST Sets and Maps`: why ordered trees are useful
